# Level Up Builders

A responsive construction portfolio starter built with React, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Build for deployment

```sh
npm run build
```

Vercel can deploy this Vite app with the default settings: build command `npm run build`, output directory `dist`.

Project photography is currently served from Unsplash. Replace the sample imagery, project details, contact email, and company copy with approved business content before launch.
