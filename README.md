# Level Up Builders

A responsive construction portfolio starter built with React, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Build for deployment

```sh
npm run build
```

Vercel can deploy this Vite app with the default settings: build command `npm run build`, output directory `dist`.

The portfolio gallery uses photos of three completed projects in the project cards, hero, and statement sections. Replace the sample contact email and company copy before launch.
